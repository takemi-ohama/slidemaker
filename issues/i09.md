## 📝 実行計画（7ステップ）

### ステップ1: ツールインストール

**担当**: Main Agent（Directorが直接実行）

```bash
# LibreOffice Impress（PowerPoint→PDF変換）
sudo apt-get update
sudo apt-get install -y libreoffice-impress --no-install-recommends

# poppler-utils（PDF→画像変換）
sudo apt-get install -y poppler-utils
```

**所要時間**: 3〜5分

---

### ステップ2: PowerPoint座標検証

**担当**: `ndf:qa`エージェント

**タスク**:
1. Office-PowerPoint-MCP-Serverで最新PowerPoint（v3）を開く
2. 最初の3スライドの要素座標をチェック
3. スライド境界内に収まっているか検証
   - スライド幅: 9,144,000 EMU (960 pixels × 9525 EMU/pixel)
   - スライド高さ: 5,143,500 EMU (540 pixels × 9525 EMU/pixel)
4. 問題があればレポート

**使用ツール**:
- `mcp__powerpoint__open_presentation`
- `mcp__powerpoint__get_slide_info`

**期待される確認ポイント**:
- 要素の `left`、`top`、`width`、`height` が妥当な範囲内か
- 水平・垂直オーバーフローがないか
- 座標が2倍スケールになっていないか（過去の問題）

**Main Agentへの指示内容**:
```
「output/MDX_Strategic_Engine_2026_v3.pptxをPowerPoint MCPで開き、最初の3スライドの要素座標を検証してください。スライド境界（width: 9144000 EMU、height: 5143500 EMU）内に収まっているか、水平・垂直オーバーフローがないかチェックし、問題があればレポートしてください。」
```

**所要時間**: 5〜10分

---

### ステップ3: キャプチャ画像生成

**担当**: `ndf:scanner`エージェント

**タスク**:
1. LibreOfficeでPowerPoint→PDF変換
2. pdf2imageでPDF→画像変換（最初の3ページのみ）

**実行コマンド**:
```bash
# PowerPoint→PDF
libreoffice --headless --convert-to pdf --outdir output/pptx_captures output/MDX_Strategic_Engine_2026_v3.pptx

# PDF→画像（Python）
cd /home/ubuntu/work/slidemaker
uv run python -c "
from pdf2image import convert_from_path

pdf_path = 'output/pptx_captures/MDX_Strategic_Engine_2026_v3.pdf'
images = convert_from_path(pdf_path, dpi=150)

for i, image in enumerate(images[:3], 1):
    output_path = f'output/pptx_captures/slide_{i:03d}.png'
    image.save(output_path, 'PNG')
    print(f'Saved: {output_path}')
"
```

**Main Agentへの指示内容**:
```
「output/MDX_Strategic_Engine_2026_v3.pptxをLibreOfficeでPDFに変換し、pdf2imageで最初の3ページを画像化してoutput/pptx_captures/slide_001.png〜slide_003.pngに保存してください。DPI=150で変換してください。」
```

**所要時間**: 3〜5分

---

### ステップ4: 画像比較

**担当**: `ndf:scanner`エージェント

**タスク**:
1. Readツールで両画像を読み込み
   - 元PDF: `output/temp/pdf_pages/page_001.png` 〜 `page_003.png`
   - 生成PPTX: `output/pptx_captures/slide_001.png` 〜 `slide_003.png`
2. 視覚的に比較（1〜3ページ）
3. 差異をレポート

**比較ポイント**:
- **画像要素の完全性**: 図表の全要素（ボックス、矢印、ラベル等）が含まれるか
- **テキスト切れ**: テキストが切れていないか
- **レイアウト再現性**: 元PDFに近いレイアウトか
- **過去の問題再発**:
  - 1枚目: 4つの歯車図が全て表示されているか
  - 3枚目: 右側の青いボックス群が欠けていないか

**Main Agentへの指示内容**:
```
「元PDF画像（output/temp/pdf_pages/page_001.png〜page_003.png）と生成PPTX画像（output/pptx_captures/slide_001.png〜slide_003.png）を比較してください。画像要素の完全性、テキスト切れ、レイアウトの再現性について差異をレポートしてください。過去の問題（1枚目の歯車図、3枚目の青いボックス群）が解消されているか特に注目してください。」
```

**所要時間**: 5〜10分

### ステップ5: 問題点の特定

**担当**: `ndf:qa`エージェント

**タスク**:
1. ステップ2（座標検証）とステップ4（画像比較）の結果を統合分析
2. 問題点を分類

   - **画像要素の部分欠落**: 図表の一部しか表示されない
   - **テキスト切れ**: テキストボックスのサイズ不足
   - **その他**: レイアウト崩れ等
3. 問題の根本原因を推定
4. 修正が必要なファイルを特定

**修正候補ファイル**:
- `src/slidemaker/image_processing/analyzer.py` （座標変換ロジック）
- `src/slidemaker/workflows/conversion.py` （画像切り出し、padding調整）
- `src/slidemaker/llm/prompts/image_processing.py` （プロンプト改善）

**Main Agentへの指示内容**:
```
「座標検証と画像比較の結果を統合分析し、問題点を分類（座標スケールエラー、画像要素欠落、テキスト切れ等）してください。問題の根本原因を推定し、修正が必要なファイル（analyzer.py、conversion.py、image_processing.py）を特定してください。」
```

**所要時間**: 5〜10分
